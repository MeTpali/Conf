# Лабораторная работа №1. Взаимодействие с web-клиентом

**Вариант 5 (номер в списке 19):** Преобразователь температуры — конвертер °C ⇄ °F.

## Структура

```
lab1/
├── server/            — Node.js web- и WebSocket-сервер без зависимостей
│   ├── server.js
│   ├── test-server.js
│   └── public/        — HTML, CSS и JavaScript
└── aurora-client/     — нативное приложение Qt/QML/C++ и CMake
```

## Запуск

Нужен Node.js версии 14 или новее. Этот же сервер используется нативным
клиентом из `aurora-client` по протоколу WebSocket.

```
cd lab1/server
node server.js
```

Сервер выведет адреса, например:

```
  Локально:          http://localhost:8080
  В локальной сети:  http://192.168.1.42:8080   (Wi-Fi)
```

- **ПК:** открыть `http://localhost:8080`.
- **Телефон с ОС Аврора:** подключить к той же Wi-Fi сети и открыть в браузере адрес «В локальной сети».
  Если не открывается — разрешить входящие подключения к Node.js в брандмауэре Windows (порт 8080).

После запуска сервер также выводит адрес для нативной части ЛР1, например
`ws://192.168.1.42:8080/ws`. Его нужно указать в мобильном приложении.

## API

| Метод  | URL            | Тело / ответ |
|--------|----------------|--------------|
| POST   | `/api/convert` | `{"value": 36.6, "from": "C"}` → `{"input":36.6,"from":"C","output":97.88,"to":"F","time":"..."}` |
| GET    | `/api/history` | последние 10 преобразований |
| DELETE | `/api/history` | очистить историю |

## WebSocket API нативного клиента

Подключение выполняется к `/ws`. Клиент отправляет JSON-сообщения:

- `{"type":"convert","value":36.6,"from":"C"}` — преобразовать температуру;
- `{"type":"history"}` — получить последние 10 результатов;
- `{"type":"clearHistory"}` — очистить историю.

Сервер отвечает сообщениями `connected`, `result`, `history` или `error`.

Сервер проверяет ввод: число, единица `C`/`F`, температура не ниже абсолютного нуля (−273.15 °C / −459.67 °F).

## Соответствие требованиям

- **Серверная логика** — формулы `F = C·9/5 + 32`, `C = (F − 32)·5/9` выполняются на сервере (`server.js`, функция `convert`).
- **HTML / CSS / JS** — отдельные файлы в `public/`.
- **Обработка нажатий** — кнопки «Преобразовать», «⇄» (поменять единицы), «Очистить» (`app.js`).
- **Асинхронный JS** — `async/await` + `fetch` при конвертации, цепочка `Promise.then/catch` при очистке истории.
- **Адаптивность** — `@media (max-width: 768px)`, `(max-width: 480px)`, `(min-width: 1200px)`, `(prefers-color-scheme: dark)`.
- **Qt/C++** — клиент находится в `aurora-client`, собирается только CMake.
