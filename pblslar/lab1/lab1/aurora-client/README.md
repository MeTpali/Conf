# Лабораторная работа № 1. Клиент Qt/C++ для ОС Аврора

Вариант 5 для номера в списке 19: преобразователь температуры °C ⇄ °F.

Приложение использует Qt Quick и Sailfish Silica. C++-контроллер проверяет
введённую температуру, формирует JSON-запросы и разбирает ответы сервера.
WebSocket-клиент RFC 6455 реализован в C++ поверх разрешённого для ОС Аврора
класса `QTcpSocket`.

## Запуск

1. На ПК запустить сервер: `cd lab1/server && node server.js`.
2. Подключить телефон к той же сети и разрешить входящие подключения к порту
   8080.
3. В Aurora IDE открыть `lab1/aurora-client/CMakeLists.txt`, выбрать комплект
   под архитектуру эмулятора или телефона, собрать и запустить.
4. В приложении ввести адрес, напечатанный сервером, например
   `ws://192.168.1.42:8080/ws` (в эмуляторе — `ws://10.0.2.2:8080/ws`).

Проект должен лежать внутри рабочей области Аврора SDK.

## Протокол

Клиент отправляет `{"type":"convert","value":36.6,"from":"C"}`. Сервер
возвращает сообщение `result` и затем общую историю web- и мобильного
клиентов. Также используются команды `history` и `clearHistory`.

Каталог `tests` содержит консольную интеграционную проверку C++-клиента:
она подключается к настоящему серверу и проверяет результат
`36,6 °C = 97,88 °F`.
