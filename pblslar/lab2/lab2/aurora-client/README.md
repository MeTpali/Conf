# Нативный клиент ЛР2

Открыть `CMakeLists.txt` в Aurora IDE. Проект использует Qt Core, Network,
Sql, QML, Quick и Aurora App. Для эмулятора адрес ПК —
`https://10.0.2.2:8443`; для телефона укажите HTTPS-адрес ПК в локальной сети.

Тестовый самоподписанный сертификат разрешается переключателем в интерфейсе.
Изменения сначала записываются в SQLite, затем синхронизируются с REST API.
