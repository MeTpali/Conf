# Лабораторная работа 2

Вариант 9 для номера в списке 19: музыкальная коллекция.

- `server` — HTTPS REST API `/api/v1`, cookie-аутентификация, CRUD, корректные
  HTTP-коды, ETag, Cache-Control, Last-Modified, OpenAPI и тестовая web-страница.
- `aurora-client` — CMake-проект Qt/QML/C++ с QNetworkAccessManager,
  QJsonDocument, постоянным cookie/QSettings, SQLite offline-кэшем и очередью
  синхронизации.

Запуск сервера описан в `server/README.md`. В Aurora IDE нужно открыть
`aurora-client/CMakeLists.txt`.
