# Нативный клиент ЛР3

CMake-проект Qt/QML/C++ для ОС Аврора. Клиент обращается к `/api/v1/health`
через nginx, показывает фактический backend и версию, автоматически повторяет
запросы с экспоненциальной задержкой и принимает push-сообщения по WebSocket.

Для эмулятора используются `http://10.0.2.2:8080` и
`ws://10.0.2.2:8080/ws/notifications`.
